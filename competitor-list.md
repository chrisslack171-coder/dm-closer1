# Competitor List

Accounts in your niche to study for hooks, formats, and trends. Used by the
`ig-competitor-research` skill (Instagram + TikTok).

**How to use:** add each competitor under the right section as a profile URL.
**Order = priority** — the skill defaults to the first 5 handles total. Then run
`/ig-competitor-research` with no handles and it reads this file. (Or pass
handles after the command to override this list for a one-off.)

To add an account, copy a block below, change the name/URL/notes. The only part
the skill *needs* is the **URL** line — Notes are just for you.
